# Imperial Fiesta 2025 | BBAU Lucknow

Imperial Fiesta is the annual welcome celebration for junior students at Babasaheb Bhimrao Ambedkar University (BBAU), Lucknow. This repository contains the source code for the event's official website, designed to facilitate registrations and provide essential information to attendees.

## 🚀 Features

- **Multi-step Registration:** A seamless multi-step form for attendee details and event preferences.
- **Secure Payments:** Integrated PhonePe payment gateway for pass purchases.
- **Responsive Design:** Fully mobile-friendly interface built with Tailwind CSS.
- **Real-time Validation:** Client-side form validation for a better user experience.
- **Event Information:** Detailed schedule, venue, and attraction highlights (Live DJ, Talent Showcase, Games).
- **Legal & Transparency:** Dedicated pages for Terms of Service, Privacy Policy, and Refund Policy.

## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS (via CDN)
- **Backend:** Node.js (hosted on Vercel), Firebase/Firestore integration
- **Payment Gateway:** PhonePe API
- **Typography:** Poppins (Google Fonts)
- **Icons:** Font Awesome 6
- **Interactivity:** Vanilla JavaScript

## 📁 Project Structure
